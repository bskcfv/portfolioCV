# 💼 Portafolio

Este portafolio reúne mis proyectos más relevantes en **desarrollo backend** y **arquitectura de bases de datos**, con enfoque en autenticación, gestión de datos y optimización de sistemas.

## 🚀 Proyectos Destacados

### 🧾 Inventory Management System
Sistema de inventario con autenticación **JWT**, CRUD de productos y conexión a **MongoDB**.  
Diseñado para gestionar existencias y movimientos de stock de forma eficiente.

🔗 [Repositorio](https://github.com/bskcfv/InventarioBsk)

---

### 💰 Gario
Sistema backend desarrollado en **Node.js** para administrar finanzas personales mediante registro de ingresos, gastos y generación de reportes.  
Incluye autenticación **JWT** y conexión a **MySQL**.

**Rol:** Backend Developer | Responsable del backend, base de datos y autenticación JWT (2 integrantes)

🔗 [Repositorio](https://github.com/60GodlysecondsGroup/Gario_BackEnd)

---

### 🏪 Perrigry-S
Plataforma de gestión para empleados y administradores de tienda, desarrollada con **Next.js**, **PostgreSQL** (desplegado en **NeonDB**) y **MongoDB Atlas**.  
Permite administrar usuarios, ventas y autenticación mediante **reconocimiento facial**.

**Rol:** Backend Developer | Encargado del backend, bases de datos (PostgreSQL y MongoDB) y autenticación JWT (3 integrantes)

🔗 [Repositorio](https://github.com/PerriGry/perrigry-s)

---

### 🗃️ E-Perrigry-DB
Base de datos diseñada en **PostgreSQL** para un sistema de ventas con carrito de compras.  
Incluye **tablas**, **secuencias**, **procedimientos**, **funciones**, **triggers** y **vistas** que optimizan el flujo completo de ventas.

🔗 [Repositorio](https://github.com/bskcfv/E-Perrigry-DB)
